# 무주군 뉴스 카카오톡 알림 (매일 20:00 KST)

Claude Code 루틴(Routine)이 매일 19:55(KST)에 새 세션을 열어 아래 지시문을 실행한다.
발송 도구: PlayMCP `KakaotalkChat-MemoChat` (카카오톡 나에게 보내기, 1건당 200자 제한).

## 루틴 지시문

오늘(KST) 인터넷 뉴스에서 전북 무주군 관련 기사를 모아 요약하고 카카오톡 '나에게 보내기'로 발송하라.

1. 수집: WebSearch로 아래 검색어를 각각 조회한다.
   - "무주군", "무주군 오늘 뉴스", "무주 군수", "무주군의회", "무주 태권도원", "무주 덕유산", "무주 반딧불축제"
   - 결과가 부족하면 "무주군 {오늘 날짜}"로 추가 검색한다.
2. 선별:
   - 최근 24시간 이내 기사만 포함. 날짜가 확인되지 않으면 제외한다.
   - 경남 거창·충북 영동 등 타 지역 기사, 날씨 자동생성 기사, 광고성 글은 제외한다.
   - 같은 사안의 중복 보도는 1건으로 합친다.
   - 중요도 순(군정 주요 정책·예산·사건사고 > 행사·축제 > 기타)으로 최대 8건.
3. 작성 형식 (메시지 1건당 200자 이하):
   - 1번째 메시지: "[무주군 뉴스 M/D(요일)] 오늘 N건" + 한 줄 총평
   - 이후 메시지: 기사 2~3건씩 묶어 "▪제목 요약(언론사)" 형태, 기사당 1줄
   - 기사 내용에 없는 추정·해석은 쓰지 않는다.
4. 발송: mcp__PlayMCP__KakaotalkChat-MemoChat 로 순서대로 발송한다. 총 5건 이내.
5. 해당 기사가 없으면 "[무주군 뉴스 M/D] 오늘은 확인된 무주군 관련 기사가 없습니다." 1건만 발송한다.
6. 발송 실패 시 1회 재시도하고, 그래도 실패하면 세션 결과에 실패 사유를 남긴다.

## 운영 메모

- 시각 변경·중지: claude.ai의 Routines 목록에서 수정/비활성화.
- 이 환경의 네트워크 정책상 네이버·구글뉴스 직접 접속은 차단되어 WebSearch 결과에 의존한다. 지역 소식지 기사 누락 가능성이 있다.
